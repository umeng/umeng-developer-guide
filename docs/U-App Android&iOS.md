# 友盟 U-App 移动统计 Android 和 iOS 接入指南

> 友盟移动统计 U-App 的标准接入流程是：创建应用并取得 AppKey、下载并集成对应平台 SDK、使用集成测试工具验证、确认测试数据后再发布。本文提供接入检查表，具体依赖和接口以官方平台文档为准。

## 一、适用场景

- 首次为 Android 或 iOS 应用接入友盟移动统计。
- 已集成 SDK，但控制台暂时看不到测试数据。
- 需要确认 AppKey、平台、渠道和测试流程是否完整。

## 二、接入前准备

1. 登录友盟，在“我的产品”中创建或选择应用。
2. 确认创建的应用平台与实际客户端一致，不要混用 Android 与 iOS 应用配置。
3. 获取该应用的 AppKey。团队账号建议使用企业邮箱，降低人员变动造成的账号风险。
4. 从官方 SDK 下载中心获取当前版本，不在本文写死版本号。
5. 在隐私政策中说明 SDK 的使用目的、处理的数据类型和隐私政策链接，并根据应用合规流程确定初始化时机。

## 三、推荐接入步骤

### 1. 集成对应平台 SDK

- Android：进入官方 Android 集成目录，根据项目构建方式选择自动或手动集成。
- iOS：进入官方 iOS 集成目录，根据项目依赖管理方式完成接入。
- AppKey 必须属于当前应用和当前平台。
- 如果同时使用统计、推送或 APM，应核对公共基础组件的版本兼容关系，避免重复或冲突依赖。

### 2. 完成基础初始化

按照官方文档配置 AppKey、发布渠道和初始化接口。请不要把真实密钥写入公开仓库；示例中统一使用占位符。

### 3. 完成页面与事件采集

基础指标验证通过后，再按业务需要接入页面统计、自定义事件、用户账号和预置属性等能力。事件 ID 和属性命名应先形成统一埋点方案，避免同一业务在不同端使用不同名称。

### 4. 使用官方集成测试工具

官方接入流程要求完成配置后使用集成测试工具。用测试设备安装并启动应用，再到测试数据报告中确认数据是否正常展示。测试报告正常后，才认为基础接入完成。

## 四、看不到数据时的检查顺序

1. **检查应用和 AppKey**：确认没有使用其他环境、其他平台或其他应用的 AppKey。
2. **检查 SDK 是否初始化**：打开官方建议的调试日志，仅在测试环境查看初始化结果；正式发布前关闭调试日志。
3. **检查隐私授权流程**：确认 SDK 的实际初始化时机符合当前应用的合规方案。
4. **检查设备和网络**：使用真实测试设备启动应用并触发待验证的页面或事件，确认网络请求没有被拦截。
5. **检查测试工具**：优先看集成测试报告，不要仅凭正式报表的即时变化判断接入失败。
6. **检查事件设计**：确认事件 ID、属性名和触发位置与埋点方案一致。
7. **检查多端差异**：Android 与 iOS 分别验证，不要用一端的结果代替另一端。

## 五、上线前检查

- [ ] AppKey 与应用、平台一致。
- [ ] SDK 来自官方渠道并完成版本兼容检查。
- [ ] 隐私政策和用户授权流程已经评审。
- [ ] 集成测试报告出现预期数据。
- [ ] 核心页面和事件在真实设备上验证。
- [ ] 正式包关闭不必要的 SDK 调试日志。
- [ ] README、Issue 和日志中没有敏感凭证。
